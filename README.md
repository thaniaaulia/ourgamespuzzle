# 🧩 PuzzleVerse

PuzzleVerse adalah koleksi mini game berbasis HTML, CSS, dan JavaScript yang bisa langsung di-host menggunakan GitHub Pages.

## Game
- 🧠 Memory Match
- 🔢 Number Merge
- 🔤 Word Scramble
- 💡 Lights Out

## Cara menjalankan
Buka `index.html` di browser.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Masuk ke **Settings → Pages**.
4. Pilih branch `main` dan folder `/root`.
5. Simpan, lalu buka URL GitHub Pages kamu.

Tidak membutuhkan backend.
